# Phase 4 audit — October 27, 2026

**Phase 4 of the usable demo is complete. Phase 5 has not started.** Alpha.13 passes the existing binary interest/quality development gate after the corrections below. New topic, subject, depth and ordinal-quality heads are implemented and tested but have no real structured ratings yet, so personal validation of those heads remains provisional. Completion is a scoped demo milestone, not a claim of bug-free software, optimal ranking or proven superiority.

Release identities: Python `0.1.0a13`, npm/plugin `0.1.0-alpha.13`, SQLite schema 10, learning model version 6, evidence rubric 3 and feature snapshot version 1. Historical feature snapshots remain readable; model versioning determines their effective scoring interpretation.

## Corrections

- Complete Bilibili provenance metadata now gates quality fitting. A provenance change invalidates the shared learning epoch even if it arrives through the other platform's pipeline; view-count-only changes do not. Relevant evidence contexts are fetched in batches rather than one query per rating.
- A metadata response with an unfamiliar integer copyright enum retains its verified description and tags. The observed value `3` is stored as unrecognized, without interpreting it as original or reposted. Previously it incorrectly produced an inaccessible/schema failure.
- Evidence inheritance now selects an actual prepared evidence bundle, excluding newer metadata-only jobs. An interrupted inherited review resumes its existing checkpoint. Verified repairs are appended as derived quality-feature revisions; original scorecards, rating snapshots and user comments remain intact. Publication rechecks metadata inside its short write transaction.
- Unknown criteria use an uncertain 0.5 prior and separate missingness predictors. They cannot inherit a high holistic grade based on the source lecturer's teaching. The assessment prompt distinguishes uploader contributions from source material and does not detect synthetic speech.
- Dense and sparse inference reject bounded priors, undeclared/nonfinite features, duplicate parameters and non-Bernoulli labels. Unused bounded sampling code was removed. Unseen ordinal metadata effects retain their prior variance.
- Topic priors have durable parent-domain anchors reconstructed from the earliest explicit topic/depth action. Edits and clears preserve the anchor; an additional dislike cannot raise interest merely by switching the associated parent domain. Explicit onboarding changes remain possible.
- Evaluation excludes superseded legacy votes, counts abstentions independently by channel/platform and checks every active main response type. Unknown-level depth reviews cannot certify known-level depth predictions. A newly activated response type cannot inherit a frozen binary evaluation.
- Loss differences and reliability intervals resample whole creator groups. Main response checks require at least six held-out creator groups. Read-only status never fits a missing model, and status reuses its source data rather than reading/fitting twice.
- Future calibration selection excludes already-trained creators from both feedback formats, caps repeated retrieval-family combinations and favors uncovered available domains. C, C++, C# and C* remain distinct normalized labels. This does not establish complete semantic deduplication or undo the historical cohort's narrow coverage.

## Theory review

The [scoring contract](../SCORING.md) gives the assumptions and proof sketch. Exact finite-dimensional posterior consistency requires stationary conditional responses, a correctly represented identifiable prediction target, positive informative coverage and fixed proper full-support priors. MAP/Laplace inference and the finite quadrature are approximations, with numerical checks and conditional asymptotic justification. Each Dirichlet topic/level group needs its own increasing number of distinct-video observations. Repeated edits are one effective observation.

The overall and ordinal transfer stages use plug-in offsets, so their sufficient conditions also require uniformly stabilizing component offsets. Averaging topic scores and applying suitability odds are ranking policies rather than proven joint approval probabilities. Growing dictionaries, user drift, sparse groups and selective abstentions have no unconditional guarantee. In particular, the user's deliberate difficulty-related abstentions do not establish the legacy model's missing-at-random assumption. Infinite feedback alone cannot solve missing coverage or unmodeled preferences.

## Performance

Same-machine comparison against the preserved Alpha.12 wheel used fixed seed 7481, 1,000 binary observations, a bias plus three nonzero random features per row, proper Gaussian priors and medians of three trials. Prediction batches contain 200 rows.

| Model size | Fit before → after | Predict 200 before → after | Maximum probability difference |
| --- | --- | --- | ---: |
| 64 parameters, dense | 549 → 89 ms (6.18×) | 15.11 → 1.64 ms (9.20×) | 0 |
| 128 parameters, sparse | 21.26 → 22.21 ms | 886 → 862 ms | 0 |

Dense fitting stops rank computation when full rank is established; dense variance sums only active features. Sparse prediction reuses its precision diagonal. The sparse timing is essentially unchanged, including a small validation overhead during fitting. These local benchmarks do not establish end-to-end platform speed or a universal maximum.

After freezing the evaluation, five warm live learning-status calls took 6.2–6.6 ms. Shared model/download concurrency, bounded resolution, retained-bundle reuse and the existing 30-minute batch allowance remain in force. Slow source access or uncached assessments can still leave a checkpoint rather than twenty complete picks.
